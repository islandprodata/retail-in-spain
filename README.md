## Fields

| Column | Description | Example |
|---|---|---|
| `country` | Country (all rows: `spain`) | `spain` |
| `founded` | Year founded (may be empty) | `1998` |
| `id` | Opaque source record ID | `uMSpbOtJJoIQzSuay0Pg6QxgPJMu` |
| `industry` | Industry (all rows: `retail`) | `retail` |
| `linkedin_url` | LinkedIn company page (domain + path) | `linkedin.com/company/kamama` |
| `locality` | City / town | `almería` |
| `name` | Company name | `kamama` |
| `region` | State / region (lowercase) | `andalusia` |
| `size` | Employee-count band | `1-10` |
| `website` | Company website domain (may be empty) | `kamama.es` |

**Notes:**
- `founded` and `website` are empty for some records.
- `size` values look like `1-10`, `11-50`, `51-200`, etc.
- CSV is UTF-8 with a header row; fields with commas are quoted.
